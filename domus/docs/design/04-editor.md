# 04 — Editor

Status: Draft v1.0

---

# Tujuan

Editor adalah pusat seluruh DOMUS Studio.

Seluruh pengalaman pengguna ditentukan oleh kualitas Editor.

Editor harus membuat pengguna merasa sedang menulis buku, bukan sedang mengoperasikan software.

---

# Filosofi

DOMUS bukan Markdown Editor.

DOMUS bukan Word Processor.

DOMUS adalah Book Writing Studio.

Editor harus menghilang.

Yang terlihat hanyalah buku yang sedang ditulis.

---

# Prinsip

1. Fokus pada tulisan.
2. Tidak ada gangguan.
3. Semua tersimpan otomatis.
4. AI hanya muncul jika diminta.
5. Preview selalu satu klik.
6. Semua perubahan aman.
7. Penulis tidak perlu memikirkan file.

# Area Editor

Editor memenuhi hampir seluruh layar.

Lebar editor disesuaikan agar nyaman dibaca.

Tidak terlalu lebar.

Tidak terlalu sempit.

---

# Toolbar

Toolbar harus sesederhana mungkin.

✍ Bold

✍ Italic

✍ Heading

✍ Quote

✍ Footnote

✍ Reference

📖 Preview

🤖 AI

Tidak ada toolbar panjang seperti Microsoft Word.

---

# Auto Save

Tidak ada tombol Save.

DOMUS menyimpan perubahan setiap beberapa detik.

Status ditampilkan:

Auto Save ✓

Jika gagal:

Auto Save ⚠

---

# Cursor

Saat buku dibuka kembali:

Cursor kembali ke posisi terakhir.

Scroll kembali ke posisi terakhir.

Penulis melanjutkan tanpa mencari paragraf terakhir.

---

# Word Counter

Bagian bawah editor menampilkan:

Words

Characters

Reading Time

Target Harian

Semua ditampilkan kecil agar tidak mengganggu.

---

# AI

AI tidak pernah muncul otomatis.

AI hanya muncul jika pengguna menekan:

🤖 AI

Panel AI muncul dari sisi kanan.

Panel dapat ditutup kapan saja.

---

# Preview

Tombol:

📖 Preview

langsung membuka Reader.

Saat kembali ke Editor:

Cursor tetap berada di posisi terakhir.

---

# Focus Mode

Shortcut:

F11

Mode Fokus:

- Toolbar disembunyikan.
- Sidebar disembunyikan.
- Status bar diperkecil.
- Hanya editor yang terlihat.

---

# Shortcut

Ctrl+I

Reference

Ctrl+Shift+P

---

# Aturan UI

Editor tidak boleh terlihat rumit.

Targetnya adalah membuat pengguna lupa bahwa ia sedang memakai aplikasi.

---

# Target UX

Pengguna membuka buku.

↓

Editor langsung terbuka.

↓

Mulai mengetik.

↓

Tidak perlu mencari tombol Save.

↓

Tidak perlu mencari file.

↓

Tidak perlu berpikir tentang struktur proyek.

Seluruh perhatian tertuju pada tulisan.

---

# Definition of Done

Editor dinyatakan selesai apabila:

✓ Auto Save bekerja.

✓ Cursor kembali ke posisi terakhir.

✓ Preview satu klik.

✓ AI muncul sesuai permintaan.

✓ Focus Mode bekerja.

✓ Penulis dapat menulis selama berjam-jam tanpa merasa terganggu.
